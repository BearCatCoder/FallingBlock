# FallingBlock

FallingBlock is a compact falling-block puzzle game being built with Godot 4.7 Classic.

This repository is also an experiment in deliberately separating AI responsibilities:

- **GPT-5.6 Terra:** product design, architecture, backlog, acceptance criteria, work management, and review.
- **Local Coding Model:** all application code, Godot scenes/resources, tests, configuration, scripts, and implementation fixes.

## Status

Design and backlog setup.

## Initial target

A polished, keyboard-controlled Linux desktop game with deterministic core rules and automated tests. The MVP intentionally excludes online services, multiplayer, accounts, monetization, and externally sourced art.
